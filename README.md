# localS
## Released
`localS` is now officially **V1.0**.

A small and simple local HTTP server for quickly hosting a directory on your computer.

For more information on how to use, [click here](HowTo.md)
### Features
* Start a local HTTP server with a custom port
* Choose the directory to host
* Works with HTML, CSS, JavaScript, and other web files
* Simple command-line interface
* Windows executable available
### Usage
```text
localS -p <port> -d <directory>
```

Example:

```bash
localS -p 8080 -d C:\html
```

Then visit:

```text
http://localhost:8080
```
